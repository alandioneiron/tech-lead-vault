# Definition of Done

Nothing is "completed" until every item is ticked. Applies to any agent.

- [ ] Requirement/spec met and demonstrated (test or evidence)
- [ ] Code reviewed (by the Tech Lead when roles are enabled)
- [ ] Tests written and passing (or justified)
- [ ] No secrets in code, commits or logs
- [ ] Living docs updated:
  - [ ] [[Development Journal]]
  - [ ] [[Changelog]] (if behavior changed)
  - [ ] Module spec in `04-Development/`
  - [ ] [[Architecture]] (if affected)
- [ ] Process checklists ticked item by item
- [ ] Decisions recorded as ADR in [[Decision Log (ADR)]] (if any)
- [ ] One line in [[AI Session Log]]
- [ ] [[Last Agent - Handoff]] rewritten (end of session)
