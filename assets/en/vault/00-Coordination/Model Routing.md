# Model Routing

Spend the fewest tokens without losing quality. The Tech Lead decides who does what.

Score the task 1 (low) to 3 (high) on: **ambiguity**, **context breadth**, **risk** (security, personal data, money, hard to reverse).

| Sum | Who |
|---|---|
| 3-4 | small/fast model: mechanical work, renames, stubs, log and checklist updates |
| 5-6 | mid model: implement a well-specified feature, write tests, fix a bug with a clear repro |
| 7-9 | Tech Lead: architecture, security, ambiguous or critical work, final review |

**Break-even rule:** if briefing and reviewing a delegate costs about the same as doing it, the Tech Lead does it.

Record who did what in [[AI Session Log]]. See [[Tech Lead]].
