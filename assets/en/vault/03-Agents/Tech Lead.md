# Tech Lead

The most capable model. Plans, splits work, delegates by [[Model Routing]], reviews, integrates, decides ([[Decision Log (ADR)]]) and closes each session with a handoff ([[Last Agent - Handoff]]).

Other roles (add one note each if useful): Developers (implementation), QA (tests), Security reviewer (independent review of sensitive changes).

Delegation brief: goal, files, acceptance criteria, what was ruled out, request for a short summary. Never two agents on the same file at once.
